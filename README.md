# Реестр медицинских изделий Казахстана: от недокументированного API до аналитического дашборда

Анализ 14 105 медицинских изделий, зарегистрированных в Казахстане за 2016–2026 годы, с использованием официальных данных о классе риска, номенклатуре и регуляторных характеристиках — собранных напрямую через backend-API НЦЭЛС, в обход публичного интерфейса, который эти данные не отображает.

## Зачем этот проект

Большинство аналитических портфолио строятся на готовых датасетах с Kaggle. Этот проект — наоборот: я взяла открытый, но технически неудобный государственный источник, разобралась, как он устроен изнутри, и довела данные до полноценной реляционной базы и дашборда. Это напрямую связано с моей профессией: я регуляторный специалист, готовлю досье на регистрацию медизделий, и здесь использую то же понимание классификации рисков (классы 1 / 2а / 2б / 3 по правилам ЕАЭС), которое обычно применяю при подготовке писем-обоснований по статье № ҚР ДСМ-281/2020

## Что внутри датасета

- **14 105** записей о медицинских изделиях, зарегистрированных или перерегистрированных с 2016 по июнь 2026 года
- Реальный **класс риска от регулятора** для каждого изделия (не выведен косвенно — взят напрямую из карточки реестра)
- Номенклатурный код и стандартизированное определение (NMIRK) для 99,7% записей
- Производитель, страна происхождения, область применения, признаки стерильности/инвазивности

## Как собирались данные: ключевая находка проекта

Официальный публичный интерфейс реестра (`register.ndda.kz`) отдаёт список изделий, но **не показывает класс риска** — это поле в публичном UI всегда пустое. На первый взгляд это выглядело как тупик для проекта.

Решение нашлось через инспекцию сетевых запросов браузера (DevTools → Network): у реестра есть отдельный backend-эндпоинт для карточки конкретного изделия (`MtMainGetById`), который не используется в публичном списке, но возвращает полный набор регуляторных данных, включая класс риска, номенклатурный код и официальное определение термина. Эта находка изменила весь объём проекта — вместо приближённой классификации по ключевым словам в названии стало возможным использовать настоящие регуляторные данные.

Процесс сбора в два шага:
1. `scripts/ndda_explore.py` — получает список всех изделий (id, производитель, страна) через основной listing-эндпоинт
2. `scripts/ndda_fetch_details.py` — проходит по каждому id и подтягивает детальную карточку с классом риска; обрабатывает сетевые сбои, сохраняет прогресс по ходу выполнения, чтобы не терять данные при обрыве соединения

Из 14 105 запросов успешными оказались 14 105 — единственная сетевая ошибка была устранена повторным запросом.

## Архитектура базы данных

Данные нормализованы в MySQL по схеме "звезда": одна фактовая таблица (`registrations`) и четыре справочника (страны, производители, классы риска, номенклатурные термины), связанные через внешние ключи. Это позволяет анализировать данные через JOIN, а не хранить повторяющийся текст в каждой строке.

```
dim_country ──┐
              ├──> dim_producer ──┐
dim_risk_class ────────────────────┼──> registrations
dim_nmirk_term ─────────────────────┘
```

Полная схема — в `sql/01_create_schema.sql`.

## Ключевые инсайты

**Структура рынка по классам риска.** Большинство изделий относится к классу 2а — со средней степенью риска (5388 изделий, 38%), за ним следуют класс 1 (3383) и класс 2б (3263). Класс 3, с самой высокой степенью риска, наименее многочислен (2071) — что логично, поскольку наиболее сложные и инвазивные технологии регистрируются реже простых расходников.

**Импортозависимость в сегменте высокого риска.** Казахстан лидирует по количеству зарегистрированных изделий класса 1 (1024 изделия — больше, чем Китай и Россия вместе взятые). Но в классе 3 картина обратная: Казахстан опускается на третье место (212), уступая США (476) и России (226). Это говорит о структурной зависимости рынка от импорта именно в сегменте сложных, высокорисковых медицинских технологий.

**Стерильность коррелирует с классом риска.** Доля стерильных изделий растёт почти линейно от класса 1 к классу 2б (15,3% → 17,2% → 19,4%), а затем резко скачет в классе 3 (63,2%). Эта закономерность ожидаема с регуляторной точки зрения — класс 3 включает наиболее инвазивные изделия с прямым контактом с тканями и кровью — и её подтверждение на реальных данных служит дополнительной проверкой достоверности собранного датасета.

**Аномальный всплеск регистраций в 2022 году.** Общее количество регистраций выросло почти в 2,6 раза по сравнению с 2021 годом (4082 против 1579), в основном за счёт новых регистраций (2316 против 864 годом ранее). Точная причина требует дополнительного изучения нормативной базы того периода.

**Топ-производитель и его профиль риска.** АО «Вектор-Бест» (Россия) — лидер по количеству зарегистрированных изделий (238), при этом 52 из них (22%) относятся к высокому классу риска — это самая высокая доля среди топ-10 производителей, что указывает на специализацию компании в более технически сложном сегменте, а не только в массовых расходных материалах.

## Дашборд

Интерактивный дашборд в Power BI (`powerbi/ndda_dashboard.pbix`) включает четыре визуализации: распределение по классам риска, сравнение топ-10 производителей по общему объёму и доле высокого риска, динамику регистраций по годам с разбивкой на новые/повторные, и долю стерильных/диагностических (ИВД) изделий по классам риска.

## Технологии

- **Python** (requests, pandas) — сбор данных через API, обработка ошибок и сохранение прогресса
- **MySQL** — нормализованное хранение, схема "звезда" с внешними ключами
- **SQL** — агрегации, JOIN, оконные функции (RANK для ранжирования стран внутри каждого класса риска)
- **Power BI** — модель данных со связями, вычисляемые меры на DAX, интерактивная визуализация
